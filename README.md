# Lotus Portfolio — Thao (Audrey) Nguyen

An interactive botanical portfolio designed with a physical zine swatch fan aesthetic, inspired by high-fashion editorial publications.

Live Site: [https://thaominhnguyen0407.github.io/portfolio2/](https://thaominhnguyen0407.github.io/portfolio2/)

## Features

- **Interactive Lotus Fan**: 8 transparent zine swatch petals radiating around a central brass eyelet grommet anchored directly on a green lotus pad.
- **Light Blue Watercolor Canvas**: Procedural sunlight caustics and interactive water ripples upon clicking.
- **High-Fashion Editorial Typography**: Bodoni Moda display serif and Cormorant Garamond italic serif.
- **Botanical Line Art Framing**: Ornate corner filigrees and hairline inner borders across all work cards and portraits.
- **Zero Vertical Scrolling**: Balanced layout engineered to fit completely within single-screen viewports (1440×605).
